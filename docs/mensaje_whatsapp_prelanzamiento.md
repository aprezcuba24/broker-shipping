## Mensaje WhatsApp

```
Hola.

Me llamo Renier Ricardo Figueredo y soy ingeniero informático. Me gustaría presentarte una plataforma que estoy desarrollando para la venta de productos a través de gestores de venta.

Durante mucho tiempo he participado en grupos de WhatsApp de gestores. Yo mismo he hecho ventas para entender cómo funciona el negocio, y en algún momento trabajé con un proveedor para conocer el proceso de punta a punta.

Lo que pretendo es ofrecer un medio donde los proveedores publiquen lo que venden y los gestores tengan un lugar donde encontrar productos para vender.

Algunas características fundamentales:

- El proveedor decide si un gestor puede ver y vender sus productos.
- El gestor envía la orden de compra con los datos del cliente y del producto.
- La plataforma consolida las comisiones que corresponde pagar a cada gestor.

Para más información:

https://renierricardo.dev/proyectos/broker

También grabé un video donde explico las características. No tiene mucha calidad pero espero que sirva:

https://www.youtube.com/watch?v=n_1WYe9y_HI

La aplicación ya está implementada, pero todavía no está disponible. El objetivo ahora es encontrar interesados y, a partir de ahí, comenzar a trabajar.

Si le interesa lo que estoy haciendo, escríbame y conversamos.
```
